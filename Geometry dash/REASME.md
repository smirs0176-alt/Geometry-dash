# 🔷 Геометрия Даш (Geometry Dash JS Clone)

Браузерная реализация популярной игры **Geometry Dash**, написанная на чистом **JavaScript (ES6 Modules)**, **HTML5 Canvas** и **CSS3**.

## 🚀 Особенности
- **Модульная архитектура**: Код разбиты на изолированные ES6-модули (Player, Obstacle, Environment, UI, Config).
- **Плавная физика**: Реалистичные прыжки с ускорением падения и динамическим вращением кубика.
- **Генерация уровня**: Случайный спавн блоков и шипов.
- **Сохранение рекордов**: Рекорд сохраняется в `localStorage`.
- **Неоновый дизайн**: Адаптированная визуальная стилистика с эффектами свечения.

## 🎮 Управление
- **Пробел / Стрелка вверх / Левый клик мыши** — Прыжок.

## 🛠️ Запуск проекта
Так как проект использует **ES6 Modules**, для локального запуска требуется локальный веб-сервер (в целях безопасности CORS в браузерах):
1. Откройте папку проекта в **Visual Studio Code**.
2. Установите расширение **Live Server**.
3. Нажмите **"Go Live"** в правом нижнем углу или кликните правой кнопкой мыши по `index.html` -> *Open with Live Server*.
